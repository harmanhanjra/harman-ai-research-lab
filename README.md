# AI Research Laboratory

Read the experiments, architectures, and evidence behind Harman’s intelligent systems.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Dynamic GitHub project loading
- Interactive filters and module inspector
- Motion with reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
